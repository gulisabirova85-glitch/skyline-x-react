# SKYLINE X — React

Loyiha siz yuborgan React kod asosida Vite loyihasiga joylandi.

## Ishga tushirish

1. Node.js 18+ o‘rnating.
2. Ushbu papkada terminal oching.
3. Quyidagilarni bajaring:

```bash
npm install
npm run dev
```

Build qilish:

```bash
npm run build
```

## Eslatma

- Reyslar, tariflar, valyuta kurslari va bron/to‘lov oqimi demo ma’lumotlar asosida.
- Tailwind CSS klasslari `index.html` ichidagi CDN orqali yuklanadi.
- Ikonkalar `lucide-react` paketidan olinadi.
